🎵 Spotify Clone - Music Player
A modern, fully functional music player web application built with vanilla HTML5, CSS3, and JavaScript. This project replicates the core features of Spotify with a clean, responsive design and smooth user experience.

✨ Features
🎮 Core Functionality

Play/Pause Control - Master play button with smooth transitions
Next/Previous Songs - Navigate through playlist seamlessly
Song Selection - Click any song to play instantly
Progress Bar - Seek to any position in the song
Volume Control - Adjust volume with visual feedback
Auto-play - Automatically plays next song when current ends

🎨 User Interface

Modern Design - Spotify-inspired dark theme with green accents
Responsive Layout - Works perfectly on desktop, tablet, and mobile
Song Covers - Display album artwork for each track
Active States - Visual feedback for currently playing song
Smooth Animations - Hover effects and transitions throughout
Now Playing - Bottom player shows current song info and cover

⌨️ Controls

Keyboard Shortcuts:

Space - Play/Pause
Arrow Right - Next Song
Arrow Left - Previous Song



🛠️ Technologies Used

HTML5 - Semantic structure and audio API
CSS3 - Modern styling with Flexbox, Grid, and animations
JavaScript (ES6+) - Interactive functionality and audio control
Font Awesome - Beautiful icons
Google Fonts - Typography (Ubuntu & Varela Round)
